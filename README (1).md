## Descripción del problema

El programa resuelve el problema de calcular el total de una compra en una tienda.
A partir del precio de un producto y la cantidad que lleva el cliente, la función
`calcular_total` multiplica ambos valores y devuelve el monto total a pagar.

## Contenido

- `calcular_total.py`: contiene la función `calcular_total(precio, cantidad)`, que
  realiza el cálculo y retorna el resultado con `return`, y un bloque principal
  (`if __name__ == "__main__":`) que llama a la función y muestra el resultado en
  consola con `print()`.

## Ejecución

```bash
python calcular_total.py
```

Salida esperada:

```
El total de la compra es: 30
```
